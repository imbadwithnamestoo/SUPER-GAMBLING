# 🎰 Super Gambling

Welcome to **Super Gambling**! This is a project I’ve been working on to practice C++. It started as a simple "guess the number" script, but it’s grown into a 1000+ line terminal game with items, save files, and a full progression system.

The goal is pretty simple: Guess the right number, bet your points wisely, and try to collect every badge without going bankrupt.
